# K.H.M.W. College website

Foundation for the public K.H.M.W. College website redesign.

## Requirements

- Node.js 20.9 or newer (use a supported Node LTS release)
- npm

## Local commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm start` — serve the production build
- `npm run lint` — run ESLint
- `npm run typecheck` — check TypeScript types

## Project boundaries

Public content must come from college-approved information already published by the college. See `docs/CONTENT_STATUS.md` before adding content. The migration archive is read-only; preserve asset provenance and do not copy assets before they are reviewed and approved.

The initial scaffold has no CMS, database, authentication, or AI backend. These remain future work under `docs/DECISIONS.md` and `docs/PROJECT_PLAN.md`.
